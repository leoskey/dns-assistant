# 管理界面视觉规范

当前有效方向：shadcn/ui neutral 风格，包含首页主机接入指引与轻量动效。沿用 React 交互和原生语义控件，以本地 CSS 实现视觉规范，图标使用 Lucide React。

## 颜色、文字与布局

- background / card：#ffffff；foreground / primary：#18181b。
- sidebar：#fafafa；muted / accent：#f4f4f5；muted foreground：#71717a；border：#e4e4e7。
- 可用状态绿色、错误红色，仅作辅助；必须同时提供状态文字。
- 字体：Segoe UI、Microsoft YaHei、PingFang SC；标题 28px，正文 14px，辅助信息 12px；数值使用等宽数字。
- 240px 侧栏，正文独立滚动，取消顶部连接状态栏，标题距顶部 32px。桌面总览依次显示解析状态、主机接入指引、三个游戏平台节点和测速预算。手机使用横向导航、单列正文及底部状态区，表格在自身区域滚动。
- 控件圆角 6px、卡片 10px，细边框和克制阴影；主操作黑底白字，次操作白底边框，辅助操作透明。

```
侧栏 | 网络总览
     | 自动状态与说明              DNS 路径
     | 有效策略数 / 后台任务数 / 同步状态
     | 连接你的主机：DNS 配置       平台设置步骤
     | Xbox          PlayStation         Switch
     | 今日测速用量                         预算
连接状态＋选优状态＋暂停／恢复（侧栏底部）
```

## 设计复核与验收

用户明确指定 shadcn 风格，因此保留其黑白灰组件语言；针对家庭 DNS 的内容层级，压缩原有展示区、保留地址族／策略同步／服务端测速边界。五个页面共享控件与间距，不增加登录、营销文案或装饰性图表。

连接状态、自动选优状态及暂停／恢复按钮统一在左下角。桌面应用网格将左侧划分为可滚动导航与独立底部状态区，正文占右侧并独立滚动；短窗口时缩小导航滚动区域，底部状态不被推出屏幕。手机采用顶部导航／正文／底部状态三行布局，底部状态左对齐、操作在旁，不覆盖正文。应用高度使用动态视口并保留安全区域。页面切换将正文滚动位置归零，平台 Tab 切换保留正文位置。

平台选优使用“全部／Xbox／PlayStation／Switch”Tab，默认全部平台；表格中地址族列同时呈现 IPv4／IPv6，当前节点与速度按地址族分别展示，不设置地址族筛选器。主操作“一键测速”提交当前平台已启用的域名；不对双地址族重复提交同一规则。每个域名提供一次测速与可展开详情。设置中的下载规则使用列表与单条展开编辑，取代每条规则同时展开的大表单。

接入检查直接提供域名与地址族的实际 DNS 应答检查，随后展示最近查询的来源、域名、解析方式和时间。不需要登记主机，不推断设备身份；配置指引统一放在首页。手机表格在自身区域滚动。

首页指引使用左右布局，左侧展示部署声明的 DNS 地址、复制操作和端口，右侧切换 PS／Xbox／Switch 菜单路径与设置步骤。手机堆叠为单列。地址缺失时显示部署检查提示；复制失败时选择地址并提示手动复制。主 DNS 使用本服务；备用可留空时留空，要求填写时可使用同地址（若主机允许），明确同机不具备故障冗余，公共备用可能绕过选优。NAS 停机前恢复自动 DNS。

路由内容采用一次 220ms 淡入和 6px 位移，主机指引切换采用 160ms 淡入，按钮按压、卡片悬停及复制反馈响应操作。检测任务运行时仅其图标旋转；状态刷新不重播页面入场。不使用持续闪烁或循环装饰。减少动态效果偏好下停用动画和位移。

验收覆盖五页桌面与 360px 手机、复制与回退、三平台指引和键盘切换、焦点可见、真实 API 数据、动画与减少动态效果、暂停恢复与解析检查、NAS 升级后的配置及历史保留。浏览器检查结果写入验证记录。
