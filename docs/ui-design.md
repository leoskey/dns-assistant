# 管理界面视觉规范

当前有效方向：shadcn/ui neutral 风格，包含首页主机接入指引与轻量动效。沿用 React 交互、原生语义控件和 Radix Select，以本地 CSS 实现视觉规范，图标使用 Lucide React。

## 颜色、文字与布局

- background / card：#ffffff；foreground / primary：#18181b。
- sidebar：#fafafa；muted / accent：#f4f4f5；muted foreground：#71717a；border：#e4e4e7。
- 可用状态绿色、错误红色，仅作辅助；必须同时提供状态文字。
- 字体：Segoe UI、Microsoft YaHei、PingFang SC；标题 28px，正文 14px，辅助信息 12px；数值使用等宽数字。
- 240px 侧栏，正文独立滚动，取消顶部连接状态栏，标题距顶部 32px。桌面总览依次显示解析状态、主机接入指引、三个游戏平台节点。手机使用横向导航、单列正文及底部状态区，表格在自身区域滚动。
- 页面主标题和各区块标题均不附描述副文案；移除主机指引底部、测速来源、节点自动识别和记录保留等说明性脚注，背景与限制留在使用和 API 文档中。操作警告放在对应控件附近，保留错误、空状态和实际运行状态；复制操作只在完成或失败后显示反馈。运行事件页面及导航统一命名为“运行日志”。
- 控件圆角 6px、卡片 10px，细边框和克制阴影；主操作黑底白字，次操作白底边框，辅助操作透明。

```
侧栏 | 网络总览
     | 自动状态                    DNS 路径
     | 有效策略数 / 后台任务数 / 同步状态
     | 连接你的主机：DNS 配置       平台设置步骤
     | Xbox          PlayStation         Switch
连接状态＋选优状态＋暂停／恢复（侧栏底部）
```

## 设计复核与验收

用户明确指定 shadcn 风格，因此保留其黑白灰组件语言；针对家庭 DNS 的内容层级，压缩原有展示区、保留默认与优选／策略同步／服务端测速边界。六个页面共享控件与间距，不增加登录、营销文案或装饰性图表。

连接状态、自动选优状态及暂停／恢复按钮统一在左下角。桌面应用网格将左侧划分为可滚动导航与独立底部状态区，正文占右侧并独立滚动；短窗口时缩小导航滚动区域，底部状态不被推出屏幕。手机采用顶部导航／正文／底部状态三行布局，底部状态左对齐、操作在旁，不覆盖正文。应用高度使用动态视口并保留安全区域。页面切换将正文滚动位置归零，平台 Tab 切换保留正文位置。

全局操作反馈使用右上角悬浮通知，不占用正文布局，出现和消失时不移动页面标题或列表。保留 6 秒自动消失、手动关闭和状态播报；窄屏限制通知宽度并允许长文案换行。临时反馈形式参考 [shadcn Toast 官方示例](https://ui.shadcn.com/docs/components/sonner)，固定位置与尺寸为本项目的布局选择。

GitHub 项目入口和当前运行版本统一放在左下角服务状态区，位于暂停／恢复按钮下方，替代右下角悬浮入口与设置页重复版本信息。版本读取后端 `app_version`，不使用前端包版本推断；GitHub 保持新标签页打开。手机在底部状态区换行显示，不遮挡保存设置。底部辅助入口模式参考 [shadcn SidebarFooter](https://ui.shadcn.com/docs/components/sidebar)。

节点列表使用“全部／Xbox／PlayStation／Switch”Tab，默认全部平台。每域名单行展示当前节点、下载速度、健康状态和最近测速时间；“一键测速”仅批量测试当前平台的已启用节点，“全部”下测试全部平台。当前平台无已启用节点时禁用批量测速，空平台显示空状态。筛选写入 URL，直接访问平台筛选链接可打开对应 Tab，左右方向键和 Home／End 切换后保持滚动位置。添加节点弹窗默认选中当前平台。复测期间保留当前解析，健康检查失败先回默认。

首页平台卡片在速度下方依次显示对应域名与 IP，三者读取同一条有效节点记录。没有有效节点时显示速度占位与“暂用上游解析”，不保留失效节点的域名。卡片不显示底部管理入口及分割线，统一通过区块的“查看全部节点”进入节点列表。沿用 [shadcn Card 示例](https://ui.shadcn.com/docs/components/card) 的标题与内容分区；域名与数值的对应关系是本项目的数据展示要求。

设置的各区块统一采用标题在上、表单在下的布局，标题与表单左侧对齐、间距 18px。表单控件最大宽度为 560px，每个输入框或多行文本框独占一行；窄屏随可用宽度缩小，不并排。区块之间使用单条分割线，备份区复用上一设置区块的底边线，不再添加重复顶边线。分组方式参考 [shadcn Field 示例](https://ui.shadcn.com/docs/components/field)，560px 宽度是本项目的布局选择。设置提供规则表 HTTPS URL、同步周期和立即同步；未保存的修改先保存，再同步，以免覆盖草稿。同步状态展示最近成功、版本和错误，失败说明继续使用上次可用规则。节点通过列表弹窗新增，已有规则通过配置 API 或备份恢复维护。自动测试仅展示时长、复测与健康间隔；策略租约随健康间隔协调，无预算控件。

解析历史页面通过弹窗提供域名 IPv4 A 的实际 DNS 应答检查，列表展示查询来源、域名、解析方式和时间。不需要登记主机，不推断设备身份；配置指引统一放在首页。查询、测速结果、运行事件分别服务端分页，默认每页 10 条，可选 20／50／100 条；筛选作用于全部保留记录。最新第一页定时刷新，翻页后固定快照，点击“刷新最新”回到实时第一页。每日汇总保留在独立分页 API 中，包含 UTC 日期、平均/峰值速度、失败/总次数、启用/切换次数和字节；与明细独立保留，当前界面不单独展示。保留策略在 API 文档中说明，列表保留记录总数、页码、空结果与加载失败反馈。手机表格在自身区域滚动。

节点新增使用平台与测试下载 URL 弹窗，域名与规则 ID 自动生成；ID 沿用已有规则生成方式，在普通 HTTP 上无需 randomUUID。新增时先读取当前配置，保留其他规则的高级字段；已有规则编辑、启停、候选和内容检查通过配置 API 或备份恢复维护。

测速记录以“全部探测／吞吐测试／健康检查／失败记录”四个 Tab 筛选，默认全部探测。切换时重新读取服务端筛选结果并回到第一页；左右方向键循环切换，Home／End 定位首尾，保留选中状态和对应面板的无障碍关联。外观沿用现有 Tab，参考 [shadcn Tabs 官方示例](https://ui.shadcn.com/docs/components/tabs)；键盘与语义参考 [WAI-ARIA Tabs 模式](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)。

节点列表的“添加节点”在模态弹窗中填写平台与测试下载 URL，提交成功后关闭并刷新列表，失败时保留输入并显示错误。底部保存、取消按钮高至少 40px、宽至少 80px，采用 14px 字号与 12px 按钮间距。支持取消、关闭按钮、Esc 和点击遮罩关闭；保存期间禁用编辑和关闭。打开时聚焦 URL，关闭后焦点返回触发按钮。交互参考 [shadcn Dialog 官方示例](https://ui.shadcn.com/docs/components/dialog)，实现复用现有原生 `dialog` 与解析检查弹窗样式；键盘和焦点行为参考 [MDN dialog 文档](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog)。

添加节点的平台选择使用 Radix Select，菜单与表单采用相同语义颜色，选中项显示勾选标记，支持方向键、文字定位和 Esc 关闭。菜单留在原生弹窗内部，避免被顶层弹窗遮挡；保存期间禁用选择。外观参考 [shadcn Select 示例](https://ui.shadcn.com/docs/components/select)，键盘、焦点和选中语义由 [Radix Select](https://www.radix-ui.com/primitives/docs/components/select) 提供。

设置保存区位于应用布局的右下角，与滚动正文分离，保留已保存／未保存／失败反馈。桌面左下角服务状态与右下角保存操作各占布局区域；手机保存行在服务状态上方，按钮右对齐，不覆盖正文。保存中禁用表单，防止请求期间的编辑被响应覆盖；成功后重设未保存状态。

首页指引先选择 DNS 优选或下载代理，左侧展示部署声明的地址、复制操作、端口及对应状态，右侧切换 PS／Xbox／Switch 菜单路径与步骤。手机堆叠为单列。代理指引涵盖 PS／Switch，并明确 Xbox 使用 DNS；不把未配置设备写成已接入。地址缺失时显示部署检查提示；复制失败时选择地址并提示手动复制。主 DNS 使用本服务；备用可留空时留空，要求填写时可使用同地址（若主机允许），明确同机不具备故障冗余，公共备用可能绕过选优。停机前恢复自动 DNS／不使用代理。

设置增加默认关闭的“启用下载代理”，沿用已有表单与右下角保存流程。首页显示启用状态、活动请求／隧道与本次运行累计下行流量，并说明协议开销和重启归零，不把隧道数量当作下载任务数。产品文案使用“服务”“服务端”或“部署设备”；NAS 只出现在部署场景说明。设计依据采用 PlayStation／Nintendo 官方网络配置，来源与观察边界见 [下载代理](download-proxy.md#设计依据)。

路由内容采用一次 220ms 淡入和 6px 位移，主机指引切换采用 160ms 淡入，按钮按压、卡片悬停及复制反馈响应操作。检测任务运行时仅其图标旋转；状态刷新不重播页面入场。不使用持续闪烁或循环装饰。减少动态效果偏好下停用动画和位移。

验收覆盖六页桌面与 360px 手机、复制与回退、三平台指引和键盘切换、焦点可见、真实 API 数据、动画与减少动态效果、暂停恢复与解析检查、目标设备升级后的配置及历史保留。浏览器检查结果写入验证记录。
