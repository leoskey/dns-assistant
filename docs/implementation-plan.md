## 当前有效需求

- 只优化公网 IPv4。下载目标域名的 AAAA 返回 NODATA，其他域名按普通上游 DNS 语义处理；清除旧 IPv6 优选及配置入口。
- 吞吐测试按相同时长读取，不设字节上限、每日预算或限速；保留串行测试、超时、取消、内容校验和公网地址边界。
- 完整测试所有去重后的合法候选，不按延迟筛掉候选；候选来自订阅规则、手工配置和各上游 A 应答，不承诺获取全部源站 IP。
- 下载速度决定排名；连接延迟只影响连接成功与否。略过预热阶段；速度接近时保持当前 IP，明显更快则在本轮完成后切换，不再等待两轮。
- 默认解析 → 本轮测试完成后优选；正常复测期间保持旧优选；健康检查失败先恢复默认并发布，再排队完整测试，通过后恢复优选。
- 默认完整复测 24 小时、健康检查 30 分钟、规则订阅更新 6 小时。健康检查只验证当前节点，策略有效期覆盖检查周期及队列等待。调度时间持久化，重启不导致全部重新测速；失败恢复测试采用退避，避免循环。
- 后台配置一个 HTTPS 规则表 URL，另有立即同步操作；下载、解析和校验完成后事务替换。失败保留上次可用配置，显示最近成功时间和失败原因。禁用任意内网访问、跨目标重定向及超大文件。
- 同域名重复任务合并；旧配置任务不得激活，恢复默认操作取消/隔离正在进行的结果。
- 节点列表展示当前节点、速度、健康与最近测速，提供平台 Tab、单条／批量测速和新增弹窗；恢复默认、固定、下次测试与完整原因通过 API 提供。
- 保留现有分页、自动清理、简化规则编辑与右下角保存按钮。增加每日速度/失败/切换汇总，保留 90 天并设总条数上限，清理明细后汇总仍在。
- 兼容旧数据库与配置备份：移除旧预算限制，迁移为低频调度，保留合法 IPv4、配置与历史；升级与回滚要求写入文档。

## 必须通过的软件验收

- 后端全套测试、Go vet、本机与 Linux/amd64、Linux/arm64 编译。
- IPv4 拒绝非法地址；目标 AAAA NODATA，普通 DNS 的缓存、CNAME、NXDOMAIN、EDNS、UDP/TCP 和 DNSSEC 边界回归。
- 测试读取超过旧字节/预算限制；同一时间窗口、连接耗时不计入吞吐、取消及 TLS/内容错误被拒绝；短样本不参与速度排名。
- 超过 8 个候选且高延迟快节点也参与；接近速度不切换，更快节点单轮切换；正常复测不提前撤销旧优选。
- 健康失败到默认、策略发布、重测恢复的真实本地 DNS/HTTP 集成；无结果时保留默认，退避和暂停不触发任务风暴。
- 规则表成功、重复任务、损坏内容、超时、私网/重定向、更新时正在测试、数据库不可写、重启恢复与旧备份迁移。
- 每日汇总准确且有界，明细删除后保留；分页筛选/快照/定时清理继续通过。
- 前端 TypeScript/Vite、Vitest；浏览器检查七个页面、订阅反馈、默认/优选/排队/失败、复测/恢复默认、分页、连接记录添加／补充节点、保存与失败重试。
- 桌面与 320px/360px 手机、短窗口：无页面级横向溢出，保存按钮可见，正文和状态栏无遮挡。

## 实机验收边界

以上通过代表软件可提交验收，不代表 NAS 已升级或主机游戏下载已提速。NAS 部署、宿主机重启与 PS/Xbox/Switch 真实下载对比需要在对应设备上另行验收，不以模拟数据代替。
