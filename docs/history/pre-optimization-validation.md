## 本地开发变更：分页、清理与设置

本轮实现接入查询、测速结果、运行事件的独立服务端分页与快照；查询持久化到 schema 2，记录写入限制条数，启动及每小时独立清理。平台规则只显示常用编辑项，设置保存区固定在右下角，并保留失败重试和未保存反馈。本轮尚未部署到 NAS，以下既有部署结果不能作为这些改动的 NAS 验收。

- TypeScript／Vite 构建与现有 2 项 Vitest 通过。
- Chromium 浏览器使用隔离的 API 测试数据验证：查询快照翻页与刷新、每页条数切换、测速筛选后翻页、事件独立分页、普通规则编辑保留高级字段、HTTP 下新增规则、保存失败重试及成功状态。
- 浏览器布局覆盖 1280×800、1024×320、360×640、360×480、320×568，分别在正文顶部与底部检查：保存按钮处于视口内、正文止于保存区之前、手机保存区与服务状态不重叠、无页面级横向溢出。
- Windows Go 1.27.2 全套 `go test ./...`、`go vet ./...` 与本机编译通过；新增回归覆盖记录分页／筛选／快照、保留上限、时间清理、空闲调度和 schema 迁移，既有测试同时通过。

此前讨论的 IPv4 专用、取消测速流量限制、降低节点更新频率、按下载速度排名、订阅源站配置与健康失败先恢复默认解析，属于后续选优流程重构，本轮记录与设置改动没有实现这些策略变化。
