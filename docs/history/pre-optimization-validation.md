验证时期：2026-10-20 的选优重构前。文档整理：2026-10-28。
本文仅保留有追溯价值的验证范围，不作为当前版本或任一设备部署状态的证明。当前结论见 [验证记录](../validation.md)，当前标准见 [验收矩阵](../acceptance.md)。

## 软件与浏览器回归

- Go 全套测试、vet、Windows 编译、TypeScript／Vite 构建及 2 项 Vitest 曾通过；Linux race 检查在初始完整实现阶段通过，不表示后续每个提交均已重跑。
- DNS 回归覆盖 UDP／TCP、A／AAAA、CNAME、缓存与过期、NXDOMAIN／NODATA、EDNS、DNSSEC 标志与地址提示旁路，以及 ACL、限流、上游失败和信任边界。
- 自动选优曾验证无需手动测速的启动闭环，包括发现、测量、发布与失败回退；旧策略的测试范围与现行行为分别判断。
- 数据回归覆盖事务、原子快照、版本幂等、备份恢复、schema 迁移，以及记录分页、筛选、快照和按时间／数量清理。
- 浏览器验证覆盖保存失败重试、未保存反馈、普通规则编辑保留高级字段、实际 DNS 应答、来源显示、主机设置指引、复制失败回退和键盘操作。
- 布局覆盖 1280×800、1024×320、360×640、360×480、320×568；导航与正文独立滚动，保存区可见、无页面级横向溢出，状态区不遮挡正文。
- Host／来源限制、跨站写入、输入上限、私网探测、内部密钥与备份边界曾通过回归。

复现入口见 [README](../../README.md)、[后端测试](../../internal/app/app_test.go) 与 [前端辅助测试](../../web/src/api.test.ts)。测试应使用当前源码重新执行，旧结果不能替代当前回归。

## 容器与部署结论

- amd64 双容器运行曾验证非 root、只读根目录、数据卷权限、健康检查、策略同步、容器重启与升级保留配置和历史。
- 管理容器停止时，DNS 使用有效快照继续应答，策略过期后回退上游。
- 初始 arm64 镜像曾在模拟环境完成启动、SQLite 初始化与健康检查；该结果不表示重构后的 arm64 运行已验收。
- 局域网 IPv4 上的 UDP／TCP、A／AAAA 与查询来源检查曾通过；AAAA 应答成功不等于 IPv6 传输已验证。
- GHCR 缓存路径曾完成上游／缓存 manifest 摘要一致性、未缓存层下载，以及本项目拉取、重建、数据保留和健康检查。该结论不保证入口持续可用，也不提供完整冷下载速度或下载收益承诺。

## 已退役行为与验证边界

旧测试曾覆盖预算、读取上限、双地址族选优、两轮切换和备用节点激活。这些行为已被公网 IPv4、按时间窗口测速、低频调度和健康失败先恢复默认解析取代，不再作为当前验收标准；schema 2 的历史记录也不表示当前仍使用该格式。现行行为与迁移要求见 [需求](../requirements.md) 和 [部署说明](../deployment.md)。

真实主机的下载完成时间、晚高峰收益、休眠唤醒与宿主机重启当时尚未验收。Nintendo 联网样本不代表实际游戏下载，服务端测速不能当作主机下载速度。后续验证应使用 [空白验收模板](../field-validation-template.md)，填写后的现场记录保存在仓库外。
