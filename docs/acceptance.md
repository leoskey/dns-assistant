# 产品验收标准

更新：2026-10-27。适用规格：[当前需求](requirements.md)。状态由 [验证记录](validation.md) 跟踪。
“实现”与“测试通过”分开判断。自动化用受控 DNS／HTTP 测试服务覆盖失败分支；公网探测及真实主机收益另行记录。

## 产品范围

中国大陆家宽，通用 Docker 部署（服务器、电脑或 NAS），React 中文界面，PS／Xbox／Switch 下载域名自动选优。DNS 与管理／探测两个进程，自动选优无需人工启动。controller 随启动提供显式 HTTP／CONNECT 下载代理，适用平台手动接入；Xbox 保留 DNS 接入。Xbox HTTP 地址转换仍为后续独立扩展，不由 DNS 覆盖或 CONNECT 伪装实现。

## 完成判定

必需软件标准全部通过才称“软件验收通过”；镜像生成不代替运行验证。没有目标部署设备／主机接入条件时，实机项保持“待实测”，交付可执行步骤与记录模板。无未经测量的性能和提速承诺。
