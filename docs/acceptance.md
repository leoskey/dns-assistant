# 产品验收标准

更新：2026-10-28。适用规格：[当前需求](requirements.md)。状态由 [验证记录](validation.md) 跟踪。
“实现”与“测试通过”分开判断。自动化用受控 DNS／HTTP 测试服务覆盖失败分支；公网探测及真实主机收益另行记录。

## 产品范围

中国大陆家宽，通用 Docker 环境，React 中文界面，PS／Xbox／Switch 下载域名自动选优。首版默认独立部署，DNS 与管理／探测两个进程，任何用户操作都不是自动选优启动的前提。Xbox HTTP 地址转换为独立后续扩展，不属于本次 DNS 首版的必需功能；它不能由 DNS 覆盖伪装实现。

## 完成判定

新增部署验收：Windows x64 安装程序与便携 ZIP 均可构建，解包后无需开发环境运行；验证管理页面、DNS UDP／TCP、内部策略同步、退出及重启持久化，安装和卸载保留独立数据。Docker 构建、Compose 校验、双服务健康及重启持久化通过。Windows 局域网防火墙、睡眠唤醒与真实主机接入单独实测。

必需软件标准全部通过才称“软件验收通过”；镜像生成不代替运行验证。没有服务主机／主机接入条件时，实机项保持“待实测”，交付可执行步骤与记录模板。无未经测量的性能和提速承诺。
