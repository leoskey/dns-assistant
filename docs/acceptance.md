# 首版完整验收标准

更新：2026-10-20。适用规格：[当前需求](requirements.md)。状态由 [验证记录](validation.md) 跟踪。
“实现”与“测试通过”分开判断。自动化用受控 DNS／HTTP 测试服务覆盖失败分支；公网探测及真实主机收益另行记录。

## 产品范围

中国大陆家宽，NAS Docker，React 中文界面，PS／Xbox／Switch 下载域名自动选优。首版默认独立部署，DNS 与管理／探测两个进程，任何用户操作都不是自动选优启动的前提。Xbox HTTP 地址转换为独立后续扩展，不属于本次 DNS 首版的必需功能；它不能由 DNS 覆盖伪装实现。

## 完成判定

必需软件标准全部通过才称“软件验收通过”；镜像生成不代替运行验证。没有 NAS／主机接入条件时，实机项保持“待实测”，交付可执行步骤与记录模板。无未经测量的性能和提速承诺。
