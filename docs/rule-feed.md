# 源站配置表


在设置中填写一个公网 HTTPS JSON 地址并保存。默认每 6 小时检查一次；“立即同步”使用已保存的地址。失败保留上次可用规则并显示最近成功时间和错误。表中的规则整体替换当前规则，手动修改后下次同步也会被表内容覆盖。

```json
{
  "version": "2026-10-20-1",
  "rules": [
    {
      "platform": "Xbox",
      "url": "http://xvcf1.xboxlive.com/Z/routing/extraextralarge.txt",
      "candidates": ["1.1.1.1"]
    }
  ]
}
```

示例 IP 仅说明格式，不证明兼容此下载域名；可以省略 candidates，程序将加入上游 A 应答。必须配置当前网络可访问且足够覆盖测速窗口的真实下载样本，不能用登录页、重定向页或小文件代替。

- 必填：表的 version，以及每条规则的 platform、url。支持 Xbox、PlayStation、Switch 的既定下载域名后缀。
- 默认：domain 从 URL 提取；id 根据域名稳定生成；enabled=true；min_bytes=65536；candidates=[]。可选 expected_prefix 用于内容校验。
- 最多 100 条规则，域名/ID 不重复；每条最多 64 个手工候选，只接受公网 IPv4。DNS 发现的候选一并测试，不保证发现全部源站 IP。
- URL 必须是最终 HTTPS 地址，使用标准端口，无账号和片段；拒绝重定向、非公网解析、IPv6、超过 1 MiB 或不完整的 JSON。连接固定到已校验的解析地址并校验证书。
- 先完整校验后事务替换；下载期间设置变化会拒绝旧同步结果。同步状态持久化，重启不会立即重复刚完成的同步。

首次启动规则来自仓库唯一维护表 `internal/app/download-rules.json`，编译时嵌入程序，使用与远程订阅相同的解析器。维护此文件后可将其发布到公网 HTTPS 地址，再在后台填写地址；没有预设一个尚未发布的订阅 URL。

内置规则作为首次启动配置。订阅更新不代表下载样本已通过内容验证，只有实际测速通过的 IP 才能生效。关闭订阅：清空 URL 后保存，已同步的有效规则继续保留。
