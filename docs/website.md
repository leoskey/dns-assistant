# 产品官网

源码位于 `website/`，独立构建为静态官网，不读取服务主机管理 API。当前采用深色科技方向，主入口指向部署指南。

## 当前需求与验收标准

- 采用黑色背景、聚焦红色光影、居中大标题与简洁导航；移除风格比较控件、硬件面板、海报和拓扑等旧候选实现。
- 页面包含产品定位、核心功能、三平台接入和部署入口。保留短文案，详细行为与兼容限制通过文档链接提供。
- 不使用 PlayStation、Xbox、Nintendo、GitHub 或参考网站的图形标志；只保留项目原标志和通用操作图标。平台兼容使用普通文字标识。
- 光影图形为原创静态 SVG，不复制参考站图片、标志或图形路径，不增加动画和外部资产依赖。
- 平台切换更新接入路径并显示唯一选中状态；支持键盘操作。命令复制成功有状态反馈，权限不可用时选择文本并提示手动复制。
- 保留管理入口仅在受信任局域网开放、测速消耗下载流量、服务主机停机前恢复自动 DNS 的操作警告。
- 不展示虚构测速、真实运行状态、用户统计或主机提速比例。
- 桌面及 360px 手机无页面横向溢出；字号不少于 12px、最多四档；焦点可见，主操作及导航文字对比度符合普通文字的 4.5:1 要求。
- 不修改原管理界面和服务主机服务，不增加依赖。
- 官网介绍通用 Docker 部署，不绑定特定硬件或设备类别；接入与停机提示统一使用服务主机称谓。

## 设计依据

2026-10-28 查看 [Raycast 官网](https://www.raycast.com/)，直接观察到黑底、红色光影、大标题和聚焦操作。当前官网借鉴其视觉方向，以自主绘制的弯曲光束表达 DNS 节点选择；这属于针对本产品的设计判断，不代表实测数据或运行监控。

颜色采用 [Radix Colors 的语义层级](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)：Slate 暗色色阶用于背景、边框与文字，Red 用于静态主视觉和少量交互强调。字体为系统字体，桌面使用 12、16、32、72px 四档，手机主标题采用 32px；控件边框 0.5px，无自动播放动画。

## 本地运行和构建

从仓库根目录执行：

```sh
npm ci --prefix web
npm run dev:website -- --port 5174
npm run build:website
```

复用已有 Vite，产物位于忽略目录 `artifacts/website/`，可部署到静态托管服务。`npm run build` 继续构建原管理界面。

## GitHub Pages

`.github/workflows/pages.yml` 在 `main` 的官网、前端依赖或构建脚本变化后自动构建部署，PR 仅构建；也可手动运行。仓库的 Pages 发布来源设为 GitHub Actions，部署环境为 `github-pages`。

官网入口：[GitHub Pages](https://leoskey.github.io/dns-assistant/)。

构建使用相对资源路径，可在仓库子路径或域名根路径托管。只上传 `artifacts/website/`；验证截图、规则与数据库、环境文件及 `.openai/` 托管身份配置不进入提交或 Pages 产物。Actions 固定提交 SHA，只有部署任务具有 Pages 与 OIDC 写权限，不需要额外保存部署密钥。

## 浏览器验证

在官网开发服务器或生产构建预览运行时执行：

```sh
npm run test:website
```

沿用 `scripts/browser-check.cjs` 的 Playwright 环境约定。`WEBSITE_URL` 可覆盖默认测试地址 `http://127.0.0.1:5174`；`PLAYWRIGHT_MODULE`、`CHROME_PATH` 分别指定现有模块与浏览器，`BROWSER_OUTPUT_DIR` 指定截图目录。

验证覆盖平台选择、键盘、命令复制与权限失败回退、站内锚点、旧候选布局与第三方图形标志移除，以及 1440、1024、768、390、360px 下的布局、字号、文字对比度和页面错误。复制权限分支使用剪贴板替身测试，实际浏览器权限行为仍受访问环境影响。

验证截图位于忽略目录 `artifacts/website-check/`，不随克隆提供。官网验证不替代服务主机、Go 服务或真实主机下载收益验收；产品运行验证以[验证记录](validation.md)为准。

### 2026-10-28 验证结果

- 官网生产构建通过，原创光影 SVG 正常加载。
- 在 `/dns-assistant/` 子路径预览上重跑浏览器验证通过，页面和元数据未将产品限定于特定设备类别；资源使用相对路径。
- 五种视口宽度、平台与键盘操作、复制成功和失败回退、站内锚点、字号、主按钮及导航文字对比度、旧布局和第三方标志移除检查通过；无页面异常或资源加载错误。
- 复核桌面和 360px 手机截图，并在内置浏览器实际打开页面。
- 本轮未修改或重测原管理界面、Go 服务、服务主机和真实游戏主机。
