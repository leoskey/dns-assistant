支持 Windows x64 单机安装与 Docker 部署。

- 新增 Windows 安装 EXE 和便携 ZIP，内置中文管理页面，无需 Docker、Go 或 Node.js。
- 安装版提供开始菜单入口，使用独立数据目录；重装及卸载保留数据。便携版默认在程序旁保存数据。
- 单机模式同时启动 DNS 和管理服务，内部通信仅绑定环回地址；Windows 程序内置时区数据。
- Docker 继续提供 Linux amd64／arm64 镜像、双容器、健康检查和持久化；示例配置固定本次发布版本。
- 官网新增 Windows 安装包、便携版与 Docker 部署入口。

下载 `*-setup.exe` 安装，或解压 `*.zip` 后运行程序。校验文件为 `SHA256SUMS`。

Docker 镜像：`ghcr.io/leoskey/dns-assistant:0.2.0`。新部署按 [Docker 部署说明](https://github.com/leoskey/dns-assistant/blob/v0.2.0/docs/deployment.md) 配置固定局域网 IPv4 与随机服务密钥，再执行 `docker compose up -d --wait`。

Windows 使用方法与数据位置见 [单机安装说明](https://github.com/leoskey/dns-assistant/blob/v0.2.0/docs/windows.md)。升级前停止服务并备份完整数据目录；Docker 升级保留 `.env` 与两个数据卷。回滚到旧数据库格式时同时恢复匹配备份。

本机与 CI 验证覆盖 Go／前端构建和测试、Windows 生命周期、安装／重装／卸载及数据保留，Docker 双架构命令烟测；完整范围见 [验证记录](https://github.com/leoskey/dns-assistant/blob/v0.2.0/docs/validation.md)。Windows 管理页在 `http://127.0.0.1:8080`，程序窗口须保持运行。管理入口只应开放给受信任局域网。

安装包尚未代码签名。真实主机下载收益、Windows 局域网防火墙及睡眠唤醒、ARM 实机运行仍需在目标环境验证。
