# v0.4.0 本地候选

状态：未公开发布。基于 v0.3.1 合入下载代理分支的界面与配套后端，保留单机安装源码和统一版本机制。

- 首页提供代理模式、DNS 模式和平台／型号配置指引，侧栏增加连接记录；节点编辑复用弹窗。
- controller 与单机程序启动 TCP 8082 HTTP／CONNECT 代理，复用允许来源网段，仅连接公网 IPv4；HTTPS 保持端到端 TLS。
- 数据库升级为 schema 4，保留配置、原有历史与调度，新增有界连接记录。升级前停止服务并冷备份完整数据卷；回退到 v0.3.1 需要恢复匹配备份。
- 继续使用 SERVER_IP，不恢复已退役的 NAS_IP 兼容分支。

本地构建、软件回归与目标部署验证分别记录，构建成功不代表已发布 GHCR、官网或 Windows 安装包。真实游戏主机收益另行实测。
