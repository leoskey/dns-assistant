# v0.4.0

- DNS、下载代理与管理功能统一为一个进程，Docker 使用一个容器和一个 `data:/data` 数据卷，无需服务密钥或环境文件。
- Windows 使用程序内管理窗口，托盘提供更新、登录后启动和退出；关闭窗口后继续运行，启动与更新重启不弹出命令行窗口。
- 首页提供 DNS／代理模式及游戏平台配置指引；支持连接记录、实际下载线路状态和指定域名重连。
- 新 HTTP 请求在优选节点或上游 DNS 变化后重新选路，线路不变时继续复用连接。HTTPS 保持端到端加密。
- 管理界面、程序窗口、托盘与安装包使用统一图标。

Docker 使用新的单数据卷布局，不自动读取旧双卷数据。镜像与 Windows 安装包分别由对应发布流程提供；实际游戏下载效果取决于网络和可用节点。
