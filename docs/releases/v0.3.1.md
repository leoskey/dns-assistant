统一应用与分发版本，修复 main 发布的容器缺少版本号标签的问题。保留 v0.3.0 的全部功能及 `SERVER_IP` 配置。

- 容器版本标签、OCI 版本、管理页、API、命令行、Windows 安装包、官网与包元数据共用 `internal/app/VERSION`。
- main 发布同时生成 `0.3.1`、`latest` 和提交号标签；Git 版本标签发布继续提供次版本标签。
- 修改 VERSION 后运行 `npm run version:sync` 同步所有当前版本入口，`npm run version:check` 检查一致性。历史发布说明保持原版本。

Docker 镜像：`ghcr.io/leoskey/dns-assistant:0.3.1`。同一版本开发期间的构建可能更新标签，需要固定内容时使用镜像 digest。升级保留 `.env`、`SERVER_IP`、服务密钥及完整数据卷。

Windows 安装 EXE、便携 ZIP 与 `SHA256SUMS` 由版本标签工作流生成，全部发布检查通过后才可下载。安装或便携版升级前停止程序并备份完整数据目录。安装包仍未代码签名；ARM 模拟运行不代表实机验收。
